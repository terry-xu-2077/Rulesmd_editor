# Rulesmd Editor

Modern Python desktop editor for Command & Conquer: Yuri's Revenge `rulesmd.ini`, with Ares-aware editing support.

> Rewrite of the legacy `terry-xu-2077/RulesmdEditor` project. The new codebase uses PySide6 instead of PyQt5 and keeps INI editing lossless: comments, order, duplicate keys, unknown Ares tags and custom mod tags are preserved.
