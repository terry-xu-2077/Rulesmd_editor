# Rulesmd Editor 说明性文本红线

这是 Rulesmd Editor 前端开发的强制 UX 文案规范。

## 红线：未经明确要求，不得主动增加说明性文本

除非需求明确要求提示、教程、说明、引导、警告或帮助文本，否则不得擅自添加任何额外说明性文字，包括但不限于：

- `title` 原生悬停提示。
- Tooltip / Popover 中的操作说明。
- “右键可以……”“点击这里……”“可通过……”一类操作教学。
- 为了“让用户知道功能存在”而新增的常驻说明、占位说明或提示条。
- 对已经由界面结构、按钮、菜单或常规交互表达清楚的功能再重复解释。

默认原则：**功能存在，不等于需要文字解释。用户没有明确要求，就不要加。**

确实需要新增说明性文本时，必须能对应到明确需求；不能以“更友好”“更容易发现”“顺手提示一下”为理由自行增加。

### 参数表右键菜单

参数表的禁用、还原、删除等操作继续通过右键菜单提供，但禁止再增加用于教学这些右键操作的悬停说明或常驻提示。
