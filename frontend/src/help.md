# Rulesmd Editor 帮助

Rulesmd Editor 用于可视化编辑《红色警戒 2：尤里的复仇》的 `rulesmd.ini`，并可在开启 Ares 支持后编辑常见 Ares 扩展参数与对象。

## 快速开始

1. 点击顶部 **打开**，选择要编辑的 `rulesmd.ini`。
2. 在左侧对象树选择单位、建筑、武器、弹头、弹体等对象。
3. 中间区域以表格方式修改参数，也可以切换到 **原文** 直接编辑 Section。
4. 修改完成后点击顶部 **保存**。
5. 在设置中指定游戏启动入口后，可使用 **启动游戏** 直接测试。

> 建议在修改大型 MOD 前先备份原始规则文件。

## 表格编辑

参数表会显示参数中文名、原始 Key、当前值和可视化控件。

- 单击一行：选中参数并在右侧显示说明。
- 右键参数行：可执行禁用、还原、删除等操作。
- 双击中文参数名：进入中文描述编辑；只有内容与内置描述不同才会保存为自定义描述。
- 带有星光标记的参数：表示 Ares 新增参数，或原版参数中被 Ares 扩展 / 解锁的能力。

自定义中文描述保存在：

```text
resources/user-descriptions.json
```

应用自带描述文件不会被修改。

## 添加参数

点击参数表底部的 **添加参数** 打开参数浏览窗口。

窗口上方搜索框只负责搜索参数目录；下方 **手动填写** 用于直接输入 `Key=Value`。

- 从列表选择参数时，下方会自动填充对应 `Key=默认值`。
- 下方手动输入已知 Key 时，上方会跳转并聚焦对应参数，但不会过滤列表。
- 手动输入目录中不存在的 Key 时，仍然允许直接添加。该能力用于 MOD 作者、Ares 新版本参数或其他编辑器尚未收录的扩展参数。

示例：

```ini
Primary=120mm
Sight=8
Custom.ModParameter=yes
```

## 新建对象

顶部 **新建对象** 可创建常见规则对象。启用 Ares 后会增加 Ares 相关对象和能力。

常见对象包括：

- 单位 / 步兵 / 载具 / 飞机 / 建筑
- 武器
- 弹头
- 弹体
- 国家
- 超级武器
- Ares 护甲
- Ares 阵营

Ares 模式下新建武器会自动处理 `[WeaponTypes]` 注册；新建护甲会写入 `[ArmorTypes]`；新建阵营会更新 `[Sides]`。

## Ares 支持

在 **设置** 中可以开启或关闭 Ares 支持。

开启后，编辑器会把原版规则和 Ares 规则尽量作为一套完整规则体系处理，同时通过星光图标标识 Ares 特性。

关闭 Ares 支持后，编辑器优先按原版 `rulesmd.ini` 规则工作。手动输入未知参数仍然允许保存，编辑器不会把参数目录当成强制白名单。

## 引用与中文名称

武器、弹头、弹体、声音等引用会尽量显示更易读的中文名称。

如果对象自身没有可靠中文名，编辑器可能根据引用关系生成名称，例如：

```text
美国大兵 · 主武器
测试单位 · 副武器
某武器 · 弹头
```

如果无法可靠判断含义，则保留原始 Section ID，避免错误翻译。

## Verses 伤害调整

弹头中的 `Verses` 可以通过专用的 **伤害百分比调整** 窗口编辑 11 种原版护甲倍率。

数值对应原版护甲顺序：

1. none
2. flak
3. plate
4. light
5. medium
6. heavy
7. wood
8. steel
9. concrete
10. special_1
11. special_2

Ares 自定义护甲使用 `Versus.<Armor>=` 形式，不属于原版 11 项 `Verses` 数组。

## 原文模式

顶部 **表格 / 原文** 可切换当前 Section 的编辑方式。

原文模式适合：

- 批量粘贴规则片段
- 添加暂未被编辑器识别的参数
- 调整注释和参数顺序
- 高级 MOD 制作者直接处理 INI 原文

切换回表格模式后，编辑器会重新解析当前 Section。

## 地图规则

地图文件可以包含规则 Section，用于覆盖全局 `rulesmd.ini` 中的同名对象参数。

编辑地图规则时可以：

- 读取地图中已经存在的规则 Section
- 为没有规则片段的地图添加对象规则
- 以表格或原文方式修改地图内部规则

地图规则只影响对应地图，不等同于修改全局 `rulesmd.ini`。

## `$Include`

编辑器支持处理包含 `$Include` 的规则文件。使用 Ares 时，应以 Ares 实际加载和覆盖顺序为准。

如果项目由多个 INI 文件组成，建议不要随意移动 `$Include`，并在保存后进入游戏验证实际覆盖结果。

## 应用配置

应用配置保存在：

```text
resources/app-config.json
```

其中包括游戏启动入口、外观、左右栏宽度、最近文件和 Ares 开关等设置。

便携版中，`resources` 位于应用主目录旁，方便整体复制和备份。

## 启动游戏与 Ares

如果使用 Ares，启动入口通常不是直接选择游戏 EXE，而应选择实际用于启动 Ares / Syringe 的 BAT 或 CMD 启动脚本。

编辑器会按 Windows Shell 启动方式打开 BAT / CMD，并使用脚本所在目录作为工作目录。

## 使用建议

- 目录和中文说明用于提高可读性，不是参数白名单。
- 高级玩家可以直接添加编辑器尚未收录的参数。
- 对自动推断的中文名称，应以实际游戏行为和可靠文档为准。
- 修改 MOD 前建议使用版本控制或保留备份。
- 大型规则修改后建议分阶段进游戏测试，便于定位错误。

## 关于帮助文档

本帮助窗口直接渲染项目中的原始 Markdown 文件：

```text
frontend/src/help.md
```
