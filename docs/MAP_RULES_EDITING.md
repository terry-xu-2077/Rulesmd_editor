# 地图内嵌规则编辑

Rulesmd Editor 支持直接打开《红色警戒 2 / 尤里的复仇》的 `.map`、`.mpr`、`.yrm` 地图文件，并编辑其中嵌入的 rules 规则片段。

## 当前行为

- 地图文件仍以完整、无损 INI 文档形式保存。
- 编辑器使用内置 `rulesmd.template.ini` 仅作为规则目录与类型参考，不会用模板覆盖地图内容。
- `[Basic]`、`[Map]`、`[Triggers]`、`[IsoMapPack5]` 等地图原生 Section 不会显示在规则对象树中。
- 地图中已有的 `[E1]`、`[HTNK]`、武器、弹头、全局规则等已知 rules Section 会出现在对象树中并可直接编辑。
- 对没有规则片段的地图，可通过“添加地图规则”创建已知规则 Section。
- 新增地图规则默认只创建空 Section；之后通过“参数”选择器添加需要覆盖的 Key，从而保持最小覆盖，而不是复制整个 rulesmd Section。
- 保存时写回原地图文件，地图原生内容保持原有顺序、注释、空行、换行与编码策略。

## 第一阶段限制

当前“添加地图规则”用于覆盖内置 rules 中已经存在的对象和全局规则。地图内创建全新的自定义单位及其 `*Types` 注册逻辑不属于第一阶段范围。
